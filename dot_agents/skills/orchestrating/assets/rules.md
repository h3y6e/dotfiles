# Rules

- Approve by scope, not by action: the brief states the approved scope of outward actions. Act within it without asking again and report what you did; ask the user before any other outward or hard-to-undo action. Only a reply from the user that names the action or scope approves it.
- On a branch, follow the `shipping` skill.
- Run dev servers and log tails in a new block next to yours: `rex split -b "$REX_BLOCK"`.
- Open reports with what happens next (`Next: merge #12`), then the evidence.
